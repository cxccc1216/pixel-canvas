## 新增功能：边缘去杂色工具（commit b32b51f）
- 需求：图片转像素后边缘有背景色差残留，现有「去色块」容差调大易误删内部相近色。
- 方案：`removeEdgeBackground(model, tolerance)` — 边界种子泛洪，从画布四边向内 BFS，逐像素容差传播（以相邻已删像素颜色为基准），只删与边缘连通的相近色区域。
- UI：工具栏新工具「边缘去杂色」（快捷键 F），点击画布执行，复用右侧容差滑块，支持撤销。Toolbar/CanvasArea/App/ColorPanel 联动。
- 测试：test-core.mjs 新增 4 组用例，全部通过；vite build 成功。
- 注意：① 容差语义为欧氏距离（Δ²和 ≤ tol²），255 vs 246 需 tol≈16 才匹配；② 前景贴边会被误删（已知局限）；③ 构建时 vite 清空 dist 被沙箱 safe-delete 拦截，需先手动 `rm -rf dist` 再 build；④ `.workbuddy/` 记忆文件已随 git 提交（是否忽略待用户决定）。
